# SG Köln-Worringen Fußball - Static Homepage Clone

Dies ist eine statische Nachbildung der Homepage von `sg-fussball.online`. Sie orientiert sich an der ursprünglichen Struktur und Darstellung und ist als GitHub Pages Website geeignet.

## Inhalt
- `index.html` – Startseite mit Hero-Bereich, Navigation, News-Sektion und Vereinshinweisen
- `css/styles.css` – responsives Layout und Design
- `js/script.js` – mobiles Menü

## Verwendung
1. Öffne das Projektordner in VS Code.
2. Lade `index.html` lokal oder veröffentliche den Ordner direkt als GitHub Pages Site.
3. Bei Bedarf kannst du weitere Unterseiten anlegen für `Unser Verein`, `Kaderübersicht`, `Mitmachen` usw.

## Hinweise
- Das Design wurde bewusst modernisiert und responsiv optimiert.
- Die originale Struktur mit Navigation, News und Vereinsfokus wurde erhalten.
- Für eine vollständige Kopie der Inhalte können Bilder und Texte noch direkt übertragen werden.
